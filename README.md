# AWS Cloud Practitioner Hands-On Labs

## Sobre o projeto

Repositório dedicado aos meus estudos práticos em AWS Cloud Computing com foco na certificação AWS Certified Cloud Practitioner (CLF-C02).

Este projeto reúne laboratórios hands-on utilizando serviços da Amazon Web Services para evolução em Cloud, Infraestrutura e Arquitetura de Soluções.
