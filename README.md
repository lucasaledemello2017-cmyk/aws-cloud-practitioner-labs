# AWS Cloud Practitioner Hands-On Labs

## Sobre o projeto

Repositório dedicado aos meus estudos e laboratórios práticos voltados para a certificação AWS Certified Cloud Practitioner (CLF-C02).

O objetivo deste projeto é consolidar conhecimentos em computação em nuvem através de hands-on reais utilizando serviços da Amazon Web Services (AWS), com foco em arquitetura básica, armazenamento, segurança, disponibilidade, gerenciamento e boas práticas em cloud computing.

Todos os laboratórios foram desenvolvidos em ambiente real da AWS, documentando configurações, testes, validações e conceitos importantes para evolução profissional em Cloud Computing.

---

# Objetivos do repositório

* Consolidar conhecimentos práticos em AWS
* Criar documentação técnica reutilizável
* Desenvolver portfólio técnico para GitHub e LinkedIn
* Apoiar preparação para certificação AWS CLF-C02
